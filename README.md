# Tiny Stack VM

A faithful interpreter for make.fun's tiny stack ISA: it runs all 40 programs of a set and answers each with exactly the bytes it prints and the exit code it ends with — wrapping 32-bit arithmetic, all ten traps, and the step and output limits.
